# StudyTrack

Настолно приложение на Python за студенти, които искат да организират
учебните си задачи и крайни срокове на едно място.

## Какъв проблем решава

Учебните ангажименти често са разпръснати между различни платформи и бележки.
StudyTrack цели да предостави общ списък със задачи, срокове и статус,
за да улесни планирането и проследяването на напредъка.

## Текущо състояние

Създадени са структурата на проекта и началният графичен прозорец.
Функционалностите за управление на задачи предстои да бъдат реализирани.

Създадени са структурата на проекта, началният графичен прозорец и инициализацията на SQLite базата данни. При стартиране автоматично се създава таблица за учебните задачи, без да се изтриват съществуващите записи.

Добавени са два автоматични теста за създаване на базата и запазване на данните при повторна инициализация. Потребителските функционалности предстои да бъдат реализирани.

## Планирани функционалности

- Добавяне на учебна задача.
- Преглед на всички задачи.
- Редактиране на задача.
- Изтриване след потвърждение.
- Отбелязване като завършена или незавършена.
- Филтриране по предмет и статус.
- Подреждане по краен срок.
- Обозначаване на просрочени незавършени задачи.

## Технологии

- Python 3.14
- Tkinter и ttk за графичния интерфейс
- SQLite за локално съхранение
- unittest за автоматични тестове
- GitHub Actions за автоматично изпълнение на тестовете — предстои

## Стартиране под Windows

Необходими са Git и Python 3.14 с поддръжка на Tkinter.

Клониране на проекта:

```powershell
git clone https://github.com/begov98/studytrack.git
cd studytrack
```

Създаване на виртуална среда:

```powershell
py -3.14 -m venv .venv
```

Стартиране:

```powershell
.\.venv\Scripts\python.exe main.py
```

На този етап не са необходими допълнителни Python пакети.

## Структура

- `main.py` — входна точка.
- `studytrack/ui.py` — графичен интерфейс.
- `studytrack/services.py` — място за бизнес логиката и валидацията.
- `studytrack/database.py` — място за работата с SQLite.
- `tests/` — място за автоматичните тестове.


## База данни

При стартиране приложението създава локална база `data/studytrack.db`.
Тя не се включва в Git.

Таблицата `tasks` съдържа идентификатор, заглавие, предмет,
краен срок във формат YYYY-MM-DD и признак за завършеност.

## Изпълнение на тестовете

От основната папка на проекта:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Тестовете използват временна база, отделна от данните на приложението.
