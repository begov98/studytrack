# StudyTrack

Настолно приложение на Python за студенти, които искат да организират
учебните си задачи и крайни срокове на едно място.

## Какъв проблем решава

Учебните ангажименти често са разпръснати между различни платформи и бележки.
StudyTrack цели да предостави общ списък със задачи, срокове и статус,
за да улесни планирането и проследяването на напредъка.

## Текущо състояние

Приложението създава автоматично локална SQLite база и показва записаните
учебни задачи в таблица със заглавие, предмет, краен срок и статус.

Добавянето на задачи се извършва през графична форма. Заглавието,
предметът и срокът са задължителни. При невалидни данни се показва
конкретно съобщение и задачата не се записва.

След успешно добавяне списъкът се обновява автоматично. Новите задачи
получават статус „Незавършена“. Данните се запазват след рестартиране.

Налични са 32 автоматични теста за базата данни, четенето, валидацията,
създаването на задачи и извикването на обновяването след успешен запис.
Тестовете се изпълняват локално и чрез GitHub Actions.

## Реализирани функционалности

- Преглед на всички записани задачи със заглавие, предмет, срок и статус.
- Добавяне на задача през графична форма с валидация на данните.
- Обновяване на списъка и показване на общия брой задачи.
- Редактиране на задача.
- Изтриване след потвърждение.
- Отбелязване като завършена или незавършена.


## Планирани функционалности

- Филтриране по предмет и статус.
- Подреждане по краен срок.
- Обозначаване на просрочени незавършени задачи.

## Технологии

- Python 3.14
- Tkinter и ttk за графичния интерфейс
- SQLite за локално съхранение
- unittest за автоматични тестове
- GitHub Actions за автоматично изпълнение на тестовете

## Стартиране под Windows

Необходими са Git и Python 3.14 с поддръжка на Tkinter.

Клониране на проекта:

```powershell
git clone https://github.com/begov98/studytrack.git
cd studytrack
```

Създаване на виртуална среда:

```powershell
py -3.14 -m venv .venv
```

Стартиране:

```powershell
.\.venv\Scripts\python.exe main.py
```

На този етап не са необходими допълнителни Python пакети.

## Структура

- `main.py` — входна точка.
- `studytrack/ui.py` — графичен интерфейс.
- `studytrack/services.py` — място за бизнес логиката и валидацията.
- `studytrack/database.py` — място за работата с SQLite.
- `tests/` — място за автоматичните тестове.


## База данни

При стартиране приложението създава локална база `data/studytrack.db`.
Тя не се включва в Git.

Таблицата `tasks` съдържа идентификатор, заглавие, предмет,
краен срок във формат YYYY-MM-DD и признак за завършеност.

## Изпълнение на тестовете

От основната папка на проекта:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Тестовете използват временна база, отделна от данните на приложението.

Тестовете се изпълняват автоматично чрез GitHub Actions при Pull Request
към main и при промяна в main. Автоматизацията използва Windows и Python 3.14.

Конфигурацията е в `.github/workflows/tests.yml`.
Резултатите се виждат в раздела Actions и в проверките на съответния PR.

## Добавяне на задача

1. Стартирайте приложението.
2. Натиснете „Добави задача“.
3. Въведете заглавие, предмет и срок във формат ДД.ММ.ГГГГ.
4. Натиснете „Добави“.

При невалидни данни формата остава отворена и показва съобщение.
При успех тя се затваря и задачата се появява в списъка.
Минали дати са разрешени. „Отказ“ затваря формата без записване.

## Приемателна проверка на ST-7

Ръчно са проверени:

- Наличие на полета за заглавие, предмет и краен срок.
- Отхвърляне на празно заглавие или предмет и стойности само с интервали.
- Отхвърляне на празен срок, неправилен формат и невъзможна дата.
- Показване на съобщение без записване при невалидни данни.
- Успешен запис със статус „Незавършена“ и незабавно обновяване на списъка.
- Добавяне на задача с минала дата.
- Отказ без записване.
- Запазване на добавената задача след рестартиране.

Реализацията е разделена между ST-9 (валидация),
ST-10 (запис и обновяване) и ST-8 (форма).

## Редактиране на задача

Изберете задача от таблицата и натиснете „Редактирай“.
Формата показва текущото заглавие, предмет и краен срок.

Променете желаните полета и натиснете „Запази“.
При невалидни данни се показва съобщение и промените не се записват.
„Отказ“ затваря формата без промени.

Редактирането запазва идентификатора и статуса на задачата.

## Изтриване на задача

Изберете задача от таблицата и натиснете „Изтрий“.
Приложението показва потвърждение със заглавието на задачата.

При „Да“ задачата се изтрива от базата и списъкът се обновява.
При „Не“ данните остават непроменени.
Изтриването е окончателно.

## Промяна на статуса

Изберете задача и натиснете „Промени статус“.
Незавършената задача става завършена, а завършената — незавършена.

Промяната се записва в базата и се показва веднага в таблицата.
Статусът се запазва след рестартиране и при редактиране на задачата.
